# Security Policy

## Supported Versions

Currently, only the latest version of the `main` branch is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.** 
If you believe you have found a security vulnerability in this project (such as a flaw in the JWT authentication, database logic, or API endpoints), please report it directly to the maintainer via email.

**Email:** 
hh9199939655@gmail.com

### What to include in your report:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The expected result vs. the actual result.

### What to expect:
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will send you regular updates about our progress in fixing the issue.
* After the issue is patched and deployed, we will publicly acknowledge your responsible disclosure (if you wish to be credited).

Thank you for helping keep this project safe!
